# Kids Smart Quiz

A beautiful, animated, offline-ready quiz web app for kids (Class 5-9). Built with pure HTML, CSS, and Vanilla JavaScript.

## Features

- 1540+ questions across 7 subjects: Math, Science, GK, English, Urdu, Islamiat, Computer
- Animated glassmorphism UI with gradient backgrounds
- Sound effects, timer, streak bonus, confetti celebrations
- Local leaderboard and score history
- Dark mode toggle
- No frameworks, no build step, no dependencies

## Hosting

1. Upload ALL files to your Hostinger/public_html folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `questions.js`
   - `sounds/` (empty folder is fine - sounds use Web Audio API)

2. Open `yourdomain.com` in any browser. Done!

## Offline Use

Works 100% offline. Just open `index.html` in any browser.
